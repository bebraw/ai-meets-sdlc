Print your first badge

Try a fictional roster on your own computer. You need Node.js 24 and Chromium for the print renderer.

  1. Download the source ZIP for version 0.1.0. Unzip it and open a terminal in the directory containing the root package.json.
  2. Install the dependencies and start the browser workspace with the badge block enabled. 
    npm ci
npx playwright install chromium
export TOOLKIT_BLOCKS=badges
npm run dev -w @sdlcai/event-toolkit
  3. Open the private organizer link printed in the terminal. Choose Print name badges, select the PDF export action and click Use example. Edit a name and run the export. The toolkit checks every row before offering Download badges.pdf.

Choose a task below. Use its block ID in TOOLKIT_BLOCKS to enable it. Combine IDs with commas, such as registration-import,check-in, to go from a ticket CSV to an arrivals desk.

Use it in your own workflow

The browser, AI assistants and your application can call the same 80 operations. Each sees the blocks and actions enabled for its role.

Connect an AI assistant

In a client that supports the Model Context Protocol (MCP), configure a stdio server. Use Node as the command and the absolute path to the built checkout’s toolkit/cli.mjs followed by mcp as the arguments.

For badge preparation, enable registration-import,badges,lanyards in the client’s environment. Ask your assistant to read event-toolkit://catalog for the available tools, input schemas and examples.

“Import this ticket CSV, check that every name fits on a badge and count lanyards by color. Include ten spare attendee lanyards.”

Call it from TypeScript

Install the package from its tarball in your application. The operation name selects its input and result types. This example orders one speaker lanyard and two attendee spares. 

import { createToolkit } from "@sdlcai/event-toolkit";

const kit = createToolkit({ enabled: ["lanyards"] });
try {
  const order = await kit.run("lanyards_count", {
    people: [{ role: "speaker" }],
    spares: [{ role: "attendee", count: 2 }],
  });
  console.log(order.total); // 3
} finally {
  await kit.close();
}

Host it for your event

The reference host runs on Node.js with SQLite. Print tools work from the data you supply. For workflows such as check-in, give the UI and MCP server the same event ID and persistent data directory so both can see an arrival as soon as it is recorded.

Bring your own storage, email and form verification through adapters. Cloudflare D1 is an option for the organizer directory. The reference host can run on your own server.
